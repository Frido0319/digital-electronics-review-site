第 1 章知识点

PN结单向导电性

PN结正向导通、反向截止，是二极管和晶体管理解的起点。

必须掌握

会判断二极管导通/截止方向，理解伏安特性和反向击穿。

从零理解

正向电压降低势垒，载流子容易通过；反向电压抬高势垒，电流近似为零。

前置知识

  • 电流方向与电压极性
  • 导体、绝缘体和半导体的区别

公式/规则

  • 本知识点无固定公式。

第 2 章知识点

共射放大电路静态工作点

静态工作点决定三极管是否在线性放大区。

必须掌握

会列直流通路并计算 IB、IC、UCE。

从零理解

没有交流信号时先把电路停在一个合适位置，交流信号才有上下摆动空间。

前置知识

  • PN结和三极管电流关系
  • 欧姆定律
  • 基尔霍夫电压定律

公式/规则

  • IB = (UCC - UBE) / RB
  • IC = βIB
  • UCE = UCC - ICRC

  • 电阻串并联等效

第 3 章知识点

理想运放虚短虚断

线性负反馈下，理想运放满足虚短和虚断。

必须掌握

会用 u+ = u-、i+ = i- = 0 推导比例、加法、减法运算关系。

从零理解

运放输出会自动调节，让两个输入端电压几乎相等，但输入端几乎不取电流。

前置知识

  • 节点电流法
  • 负反馈的线性工作条件
  • 电阻分压和反相比例关系

公式/规则

  • u+ = u-
  • i+ = i- = 0

关联作业

3.2.8 3.2.13 3.2.16

来源课件页

易错点

  • 虚短不是输入端真的短接，虚断不是反馈支路断开。

5.1.1 | 单相半波整流平均值与反向峰值

单相半波整流电路中，已知二次电压有效值 U=30V、负载电阻 RL=100Ω，求输出平均电压、电流及电源波动时二极管最高反向电压。

考点定位

rectifier_bridge

来源课件页

子题级解析

5.1.1(1) 求输出电压和输出电流平均值。

  1. 半波整流平均输出 UO=0.45U。
  2. UO=0.45×30=13.5V。
  3. IO=UO/RL=13.5/100=0.135A。

答案：UO≈13.5V，IO≈0.135A。

5.1.1(2) 电源电压波动 +10% 时求最高反向电压。

  1. 半波整流二极管最高反向电压约为 √2U。
  2. 考虑 +10% 波动，Umax=33V。
  3. URM≈√2×33≈46.7V。

答案：URM≈46.7V。

答案来源：推导答案

第 5 章作业题

5.1.8 | 单相桥式整流参数计算

直流负载 110V、55Ω，采用单相桥式整流电路供电，求变压器二次电压、二次电流有效值并选用二极管。

考点定位

rectifier_bridge

来源课件页

子题级解析

5.1.8(1) 求变压器二次电压有效值。

  1. 桥式整流无滤波时 UO = 0.9U2。
  2. U2 = 110 / 0.9 ≈ 122 V。

答案：U2 ≈ 122 V。

5.1.8(2) 求二次电流有效值。

  1. 负载电流 IO = 110 / 55 = 2 A。
  2. 桥式整流中 I2 ≈ 1.11IO。
  3. I2 ≈ 2.22 A。

答案：I2 ≈ 2.22 A。

5.1.8(3) 选用二极管。

  1. 每只二极管平均电流约为 IO / 2 = 1 A。
  2. URM = √2U2 ≈ 173 V。
  3. 实际选型应留额定裕量。

答案：二极管平均电流应大于 1 A，反向峰值电压应大于约 173 V，并留裕量。

逻辑代数与卡诺图化简

用逻辑代数或卡诺图把逻辑函数化到便于实现的形式。

必须掌握

会代数化简、卡诺图圈组、转换成与非门实现。

从零理解

化简的目标是减少门电路数量和输入端数量。

前置知识

  • 与或非基本逻辑
  • 真值表
  • 二进制变量只有 0 和 1

公式/规则

  • A + A = A
  • A·A = A
  • A + A'B = A + B
