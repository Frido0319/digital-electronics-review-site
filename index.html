第 1 章

第 1 章知识点

PN结单向导电性

PN结正向导通、反向截止，是二极管和晶体管理解的起点。

必须掌握

会判断二极管导通/截止方向，理解伏安特性和反向击穿。

从零理解

正向电压降低势垒，载流子容易通过；反向电压抬高势垒，电流近似为零。

前置知识

  • 电流方向与电压极性
  • 导体、绝缘体和半导体的区别

公式/规则

  • 本知识点无固定公式。

易错点

  • 不要把稳压二极管的反向击穿工作状态当成普通二极管损坏。

第 2 章知识点

共射放大电路静态工作点

静态工作点决定三极管是否在线性放大区。

必须掌握

会列直流通路并计算 IB、IC、UCE。

从零理解

没有交流信号时先把电路停在一个合适位置，交流信号才有上下摆动空间。

前置知识

  • PN结和三极管电流关系
  • 欧姆定律
  • 基尔霍夫电压定律

公式/规则

  • IB = (UCC - UBE) / RB
  • IC = βIB
  • UCE = UCC - ICRC

关联作业

2.4.5

来源课件页

易错点

  • 计算静态量时电容开路，不能把交流负载直接代入直流通路。

第 2 章知识点

微变等效电路法

把三极管在小信号范围内等效成线性受控源模型。

必须掌握

会画交流通路、微变等效电路，并计算 Au、ri、ro。

从零理解

先固定静态点，再只观察附近很小的交流变化。

前置知识

  • 静态工作点
  • 电容交流短路近似
  • 电阻串并联等效

公式/规则

  • Au = -β(RC // RL) / rbe
  • ri = RB1 // RB2 // rbe
  • ro ≈ RC

第 3 章知识点

理想运放虚短虚断

线性负反馈下，理想运放满足虚短和虚断。

必须掌握

会用 u+ = u-、i+ = i- = 0 推导比例、加法、减法运算关系。

从零理解

运放输出会自动调节，让两个输入端电压几乎相等，但输入端几乎不取电流。

前置知识

  • 节点电流法
  • 负反馈的线性工作条件
  • 电阻分压和反相比例关系

公式/规则

  • u+ = u-
  • i+ = i- = 0

关联作业

3.2.8 3.2.13 3.2.16

来源课件页

易错点

  • 虚短不是输入端真的短接，虚断不是反馈支路断开。

易错点与考前清单

考前清单按章节知识点汇总。每做一道题后，回到这里确认自己没有踩同类错误。

  • PN结单向导电性：不要把稳压二极管的反向击穿工作状态当成普通二极管损坏。
  • 共射放大电路静态工作点：计算静态量时电容开路，不能把交流负载直接代入直流通路。
  • 微变等效电路法：带负载和空载增益不同，不能漏掉 RC // RL。
  • 理想运放虚短虚断：虚短不是输入端真的短接，虚断不是反馈支路断开。
  • 负反馈类型判断：不要只看反馈线位置，要看取样量和混合方式。
  • 单相桥式整流：题目给的是有效值 U2，输出平均值不是 U2。
  • 逻辑代数与卡诺图化简：卡诺图圈组必须按 1、2、4、8 个相邻格，边界可相邻。
  • 组合逻辑电路设计：优先级题要先给最高优先级输出，再排除更高优先级后给低优先级输出。
  • 整流题通用提醒：不要把有效值和平均值混用，题目给出的 U2 通常是交流有效值。
