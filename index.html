本征半导体

什么是本征半导体？

专题解答

本征半导体是完全纯净、晶格完整的半导体，例如高纯硅或锗。它靠本征激发产生等量自由电子和空穴，两类载流子都参与导电，但载流子数量很少，所以导电能力较弱。

  • 知道硅、锗是四价元素

  • 知道自由电子和空穴都能形成电流

杂质半导体与多子少子

什么是杂质半导体？有哪些类型？多子、少子分别是谁？

专题解答

PN 结

PN 结怎么形成？为什么单向导电？

专题解答

P 区和 N 区接触后，多子扩散形成空间电荷区和内电场；内电场阻碍扩散、促进少子漂移，最终达到动态平衡。正向偏置时势垒降低、PN 结变窄、多子扩散增强，电流大，表现为导通；反向偏置时势垒升高、PN 结变宽，只剩很小反向电流，表现为截止。

前置知识

  • P 型和 N 型半导体

  • 扩散运动与漂移运动

  • 正向/反向偏置极性

稳压管与特性曲线

稳压管怎么工作？特性曲线怎么看？

专题解答

稳压二极管正常工作在反向击穿区。进入稳定区后，电流变化很大而两端电压变化很小，因此可用于稳压。读特性曲线时要找稳定电压 UZ、稳定电流范围、最大稳定电流 IZM 和动态电阻 rZ；rZ 越小，曲线越陡，稳压性能越好。使用时必须串限流电阻。

晶体管构成与放大/截止/饱和

晶体管怎么构成？什么时候放大、截止、饱和？

专题解答

双极型晶体管由两个 PN 结构成，有 NPN 和 PNP 两类，含发射区、基区、集电区，对应 E、B、C 三个电极。放大区：发射结正偏、集电结反偏，

IC ≈ βIB

截止区：

IB ≈ 0
IC ≈ 0

近似开关断开；饱和区：发射结和集电结都正偏，UCE 很小，近似开关闭合。模拟放大电路要求工作在放大区，数字电路常让晶体管工作在截止或饱和区。

  • PN 结偏置

  • NPN/PNP 电流方向

  • β 电流放大系数

Q 点不合适怎么调整

静态工作点 Q 点偏高或偏低怎么处理？

专题解答

Q 点应放在放大区中部，给输出信号留出上下摆动空间。Q 点过高容易进入饱和区，出现饱和失真；Q 点过低容易进入截止区，出现截止失真。固定偏置电路中可通过调整偏置电阻 RB、集电极电阻 RC 或电源 UCC 改变 IB、IC、UCE；分压式偏置电路中通过 RB1、RB2、RE 设置并稳定 Q 点。温度升高导致 IC 增大时，RE 的直流负反馈可抑制 Q 点漂移。

  • 直流负载线

放大电路静态分析求 Q 点

怎么做静态分析并求 Q 点？

专题解答

静态分析只看直流通路：电容开路、信号源置零，只保留直流电源和偏置电阻。固定偏置常用

IB ≈ (UCC-UBE)RB
IC ≈ βIB
UCE = UCC-ICRC

分压式偏置先求

V·B ≈ UCC·RB2(RB1+RB2)

再求

IE ≈ (V·B-UBE)RE
IC ≈ IE

最后

UCE ≈ UCC-IC(RC+RE)

Q 点就是 IB、IC、UCE 或 IC、UCE 组成的静态工作位置。

动态分析与晶体管线性模型

动态分析时晶体管怎么线性化、怎么化简？

专题解答

动态分析只看交流通路：耦合电容和旁路电容按交流短路处理，直流电源作交流地。晶体管在 Q 点附近小信号工作，可把 B-E 间等效为 rbe，把 C-E 间等效为受控电流源 βib。共射基本公式常写为

Au = -β(RC∥RL)rbe
ri ≈ RB1∥RB2∥rbe
ro ≈ RC

若发射极电阻未被旁路，它引入交流负反馈，使电压增益绝对值下降、输入电阻增大。

功率放大与甲乙类

功率放大电路有什么要求？甲类、乙类、甲乙类区别是什么？

专题解答

功率放大电路作为输出级，用来向负载提供足够功率，要求输出功率大、效率高、失真小、器件安全。甲类：整个周期导通，失真小但效率低；乙类：半个周期导通，效率高但有交越失真；甲乙类：导通时间大于半个周期，静态电流很小，兼顾效率并减小交越失真，互补功放常用。克服交越失真通常给两管加适当偏置，使其工作在甲乙类。

电压比较器与区间比较

电压比较器、区间/窗口比较器怎么判断？

专题解答

电压比较器把模拟输入与参考电压比较，输出跳到正饱和或负饱和，是模拟输入、数字输出的接口。基本比较器看 u+ 和 u- 谁大：

u+ > u-

子题级解析

7.6.17a

完成本题。

  1. 定义 A、B、C 为请求信号。

  2. 最高优先级

    Y·A = A

  3. 普快需在无特快时输出。

  4. 普慢需在无特快且无普快时输出。

答案：

设 A、B、C 分别表示特快、普快、普慢请求。按优先级输出：

Y·A = A
Y·B = A′B
Y·C = A′B′C

这样同一时刻最多只有一个输出为 1，并且高优先级请求会屏蔽低优先级。

7.6.17b

完成本题。

  2. 把 0、1、2、7、8、9 标为输出 1。

  3. 10 到 15 可作为无关项。

  4. 化简后转成与非门实现。

答案：

若 A 为 8 位、B 为 4 位、C 为 2 位、D 为 1 位，则

x < 3

对应 0000、0001、0010，

x > 6

对应 0111、1000、1001；10 到 15 可作无关项。卡诺图化简可得

Y = B′C′ + B′D′ + B·C·D

用与非门实现时写成

Y = ((B′C′)′(B′D′)′(B·C·D)′)′

易错点与考前清单

考前清单按章节知识点汇总。每做一道题后，回到这里确认自己没有踩同类错误。

  • PN结单向导电性

    不要把稳压二极管的反向击穿工作状态当成普通二极管损坏。

  • 共射放大电路静态工作点

    计算静态量时电容开路，不能把交流负载直接代入直流通路。

  • 微变等效电路法

    带负载和空载增益不同，不能漏掉

    RC ∥ RL
  • 理想运放虚短虚断

    虚短不是输入端真的短接，虚断不是反馈支路断开。

  • 负反馈类型判断

    不要只看反馈线位置，要看取样量和混合方式。

  • 单相桥式整流

    题目给的是有效值 U2，输出平均值不是 U2。

  • 逻辑代数与卡诺图化简

    卡诺图圈组必须按 1、2、4、8 个相邻格，边界可相邻。

  • 组合逻辑电路设计

    优先级题要先给最高优先级输出，再排除更高优先级后给低优先级输出。

  • 整流题通用提醒

    不要把有效值和平均值混用，题目给出的 U2 通常是交流有效值。
