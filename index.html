第 1 章知识点

PN结单向导电性

PN结正向导通、反向截止，是二极管和晶体管理解的起点。

必须掌握

会判断二极管导通/截止方向，理解伏安特性和反向击穿。

从零理解

正向电压降低势垒，载流子容易通过；反向电压抬高势垒，电流近似为零。

前置知识

  • 电流方向与电压极性
  • 导体、绝缘体和半导体的区别

公式/规则

  • 本知识点无固定公式。

第 2 章

第 2 章知识点

共射放大电路静态工作点

静态工作点决定三极管是否在线性放大区。

必须掌握

会列直流通路并计算 IB、IC、UCE。

从零理解

没有交流信号时先把电路停在一个合适位置，交流信号才有上下摆动空间。

前置知识

  • PN结和三极管电流关系
  • 欧姆定律
  • 基尔霍夫电压定律

公式/规则

  • IB = (UCC - UBE) / RB
  • IC = βIB
  • UCE = UCC - ICRC

第 2 章知识点

微变等效电路法

把三极管在小信号范围内等效成线性受控源模型。

必须掌握

会画交流通路、微变等效电路，并计算 Au、ri、ro。

从零理解

先固定静态点，再只观察附近很小的交流变化。

前置知识

  • 静态工作点
  • 电容交流短路近似
  • 电阻串并联等效

公式/规则

  • Au = -β(RC // RL) / rbe
  • ri = RB1 // RB2 // rbe
  • ro ≈ RC

2.4.5 2.4.7

来源课件页

易错点

  • 带负载和空载增益不同，不能漏掉 RC // RL。

第 3 章知识点

理想运放虚短虚断

线性负反馈下，理想运放满足虚短和虚断。

必须掌握

会用 u+ = u-、i+ = i- = 0 推导比例、加法、减法运算关系。

从零理解

前置知识

  • 节点电流法
  • 负反馈的线性工作条件
  • 电阻分压和反相比例关系

公式/规则

  • u+ = u-
  • i+ = i- = 0

第 5 章知识点

单相桥式整流

桥式整流让交流正负半周都以同一方向流过负载。

必须掌握

会计算输出平均电压、平均电流、二极管最大反向电压和二次电流。

从零理解

四个二极管轮流导通，把负半周翻到正方向。

前置知识

  • 二极管单向导电性
  • 正弦交流电有效值与峰值
  • 负载电阻欧姆定律

公式/规则

  • UO = 0.9U2
  • IO = UO / RL
  • URM = √2U2

第 5 章作业题

5.1.8 | 单相桥式整流参数计算

直流负载 110V、55Ω，采用单相桥式整流电路供电，求变压器二次电压、二次电流有效值并选用二极管。

考点定位

rectifier_bridge

来源课件页

子题级解析

5.1.8(1) 求变压器二次电压有效值。

  1. 桥式整流无滤波时 UO = 0.9U2。
  2. U2 = 110 / 0.9 ≈ 122 V。

答案：U2 ≈ 122 V。

5.1.8(2) 求二次电流有效值。

  1. 负载电流 IO = 110 / 55 = 2 A。
  2. 桥式整流中 I2 ≈ 1.11IO。
  3. I2 ≈ 2.22 A。

答案：I2 ≈ 2.22 A。

5.1.8(3) 选用二极管。

  1. 每只二极管平均电流约为 IO / 2 = 1 A。
  2. URM = √2U2 ≈ 173 V。
  3. 实际选型应留额定裕量。

答案：二极管平均电流应大于 1 A，反向峰值电压应大于约 173 V，并留裕量。

答案来源：推导答案
